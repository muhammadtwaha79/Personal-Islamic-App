# Ibadah Companion — Personal Worship Journal

An offline-first Android app for Salah, Quran Tilawat, Sunnah & Nawafil, personal Salawat/Dhikr and manzil reading. Native **Kotlin / Jetpack Compose / Material 3 / Room / Hilt**.

## ✨ Redesigned app (October 2026)

The previous plain UI has been replaced with a home-first dashboard and a premium visual system:

- **Illustrated Home:** six self-contained module cards—Daily Salah, Quran, Sunnah & Nawafil, Salawat & Dhikr, 40-Day Journey, and Manzils. Live prayer progress, home-first navigation, and coordinated light/dark surfaces.
- **Daily Salah:** five Fard cards, clear status badges and an explicit **choose → confirm** editing dialog for Jamaat/opening Takbeer/late/alone/missed/unknown. Friday selection requires explicit Jumu'ah/Dhuhr identification.
- **Sunnah/Nawafil:** rakah selector with deliberate completion and undo.
- **Quran:** half-para daily progress, Yaseen/Waqiah/Mulk confirmation, five confirmed Ramadan khatams separated from logged reading volume.
- **Salawat & Dhikr:** 1,200 short Salawat, 1,200 Istighfar, 1,000 Bismillah daily; 20 owner-supplied Salawat with 10x per-Fard personal counters; full Arabic reader.
- **40-Day Journey:** 20 Oct–28 Nov 2026 Takbeer-e-Ula self-report progress, not a religious ruling.
- **Manzils:** separate Dala'il al-Khayrat and Munajat-e-Maqbool reading logs, without book text.

**Owner decision:** The earlier Masnoon Duas catalog has been **removed from the active app UI and navigation**. Prior source-research docs are retained as historical provenance; legacy Room v5 tables remain to avoid data destruction. **The Masnoon Duas feature is no longer available.**

The redesigned UI is on [design/elite-home-worship-ui](https://github.com/muhammadtwaha79/Personal-Islamic-App/tree/design/elite-home-worship-ui) until its CI passes and it is merged. The currently released version may still have the old UI.

## Android APK

Builds are generated by GitHub Actions. Open the **latest green Actions run for the merged redesign**, scroll to **Artifacts**, download `ibadah-companion-debug-apk`, extract `app-debug.apk` and install it on an Android phone (Android 8.0+).

**Important:** Each CI runner can generate a different debug signing key. Installing a newer debug APK over an earlier installed build can fail with a signature conflict. Until stable release signing and export/restore exist, **do not uninstall or clear an app that contains valuable personal records** just to install a redesign. GitHub CI compiles/tests/lints and publishes APKs, but is not evidence of successful device installation.

## Data and trust

- Local-only Room SQLite (schema v5), no INTERNET permission and no analytics.
- Explicit additive database migration chain, no destructive migration introduced by redesign.
- No encrypted export/restore or reliable key-managed release-signing flow yet. Losing the phone, clearing app data or uninstalling can erase your records.
- Source-sensitive Salawat and worship-related rules have not been religiously certified. Personal streaks/targets are not a religious obligation or reward guarantee.
- **Not yet shipped:** production-grade Qaza ledger, fasting/Hijri systems, safe backup, user-controlled export, verified device migration tests and professional accessibility QA.
