# ADR-0001: Record architecture decisions

**Status:** Accepted

**Context.** Work is continued across chat sessions with no memory; reasons for decisions must live in the repository.

**Decision.** Significant technical, security and product-identity decisions are recorded as numbered ADRs in `docs/decisions/`. Changing ledger semantics, adding a permission, or adding a fiqh assumption requires an ADR.

**Consequences.** Slightly more writing; future sessions can audit and reverse decisions knowingly.
